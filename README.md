# 安全衛生推進者 管理システム

安全衛生推進者の実務管理・巡視点検・リスクアセスメント・ヒヤリハット報告を支援するWebアプリケーションです。
各事業場（現場）での日常点検・記録と、本社でのリアルタイム一元集約・ナレッジ共有、さらに **LINE公式アカウントによる二重防御アクセス制御（退職者・悪用者の即時遮断）** を備えています。

## 🌐 Web公開URL
GitHub Pages にて公開されています：  
👉 **https://susumu53.github.io/safety-health-app/**

---

## 🛡️ LINE公式・二重防御セキュリティ（退職者・悪用者の遮断機能）

本社の Google スプレッドシートにある「友だちリスト」で、対象者のステータスを **「不許可」** に切り替えるだけで、以下の二重防御が同時に発動します：

1. **第1の壁（LINE側）**: 対象者のLINEトーク画面から**リッチメニュー（ボタン）が即座に消去**されます。
2. **第2の壁（アプリ側）**: 過去のURLやブックマークからアクセスされても、LINEユーザー認証により**「⚠️ アクセス権限が無効化されています」と表示され、アプリの全機能が完全ロック**されます。

## 🚀 初期セットアップ手順（すべて無料・約5分）

### ステップ 1: 本社スプレッドシート（GAS）の作成
1. Google ドライブで新規「Google スプレッドシート」を作成（例：`全社安全衛生推進統合データベース`）。
2. メニュー「拡張機能」>「Apps Script」を開き、[google_apps_script.js](./google_apps_script.js) の内容を丸ごと貼り付けて保存（💾）。
3. 右上「デプロイ」>「新しいデプロイ」> 種類「ウェブアプリ」を選択：
   - 次のユーザーとして実行: `自分`
   - アクセスできるユーザー: `全員`
4. 「デプロイ」を押し、発行された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピー。

### ステップ 2: LINE Developers でのキー取得（任意・二重防御を使う場合）
1. [LINE Developers](https://developers.line.biz/) にログインし、プロバイダーと「Messaging API」チャネルを作成。
2. **Messaging API 設定** タブで「チャネルアクセストークン（長期）」を発行してコピー。
3. **LIFF** タブで「LIFFアプリを追加」：
   - アプリ名: `安全衛生推進者アプリ`
   - サイズ: `Full`
   - エンドポイントURL: `https://susumu53.github.io/safety-health-app/`
   - Scope: `profile`, `openid` を選択
4. 作成後に表示される **「LIFF ID」**（例: `1234567890-abcdefgh`）をコピー。

### ステップ 3: アプリとスプレッドシートへ設定
1. **アプリ側**:
   - 安全衛生推進者アプリ右上の「⚙️ 設定」を開く。
   - 「🏢 本社スプレッドシート連携 (GAS URL)」にステップ1の URL を入力。
   - 「🛡️ LINE公式 二重防御連携 (LIFF ID)」にステップ2の LIFF ID を入力して「保存する」。
2. **スプレッドシート側**:
   - スプレッドシートを開くと、メニューバーに **「🛡️ LINE連携設定」** が表示されます。
   - 「🔑 LINEアクセストークン・メニューID設定」をクリックし、ステップ2で取得したチャネルアクセストークンを入力して保存。

## 👥 現場社員の運用と退職時の管理

### 【社員の登録（入社時）】
- 社員がLINE公式アカウントを友だち追加すると、スプレッドシートの **「友だちリスト」** シートに氏名・ユーザーID・「許可」が自動追加されます。

### 【退職者・悪用者のアクセス遮断（退職時）】
- スプレッドシートの **「友だちリスト」** を開きます。
- 対象者の「ステータス」列を **「許可」➔「不許可」** にプルダウンで変更します。
- **これだけで、相手のLINEからメニューが消去され、アプリ画面も即座に完全遮断されます。**

## 📋 集約されるシート一覧（自動生成）
- 👥 **友だちリスト**: LINE表示名、ユーザーID、所属・氏名、ステータス（許可/不許可）、アクセス履歴
- 📋 **職場巡視・パトロール**: 点検箇所、担当者、合否件数、所見、問題項目
- ⚠️ **リスクアセスメント**: 作業名、危険源、重篤度×可能性スコア、判定、是正対策、期限
- 🚨 **ヒヤリハット報告**: 発生日時、場所、状況・経緯、推定原因、再発防止策
- 📚 **安全衛生教育**: 実施日、教育区分、テーマ、受講者数、所見
- ❤️ **健康管理記録**: 実施年月、受診状況、有所見者数、就業配慮事項
