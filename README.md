# 安全衛生推進者 管理システム

安全衛生推進者の実務管理・巡視点検・リスクアセスメント・ヒヤリハット報告を支援するWebアプリケーションです。
各事業場（現場）での日常点検・記録と、本社でのリアルタイム一元集約・ナレッジ共有を両立できます。

## 🏢 本社Googleスプレッドシート連携（全社データ集約）

現場の端末で安全パトロール、リスクアセスメント、ヒヤリハット等を登録した際に、**本社のGoogleスプレッドシートへリアルタイムで自動同期**させる機能が備わっています。

### 【連携の準備手順（約3分・完全無料）】

1. **Googleスプレッドシートを新規作成**
   - Google ドライブで「新規」>「Google スプレッドシート」を作成します。
   - タイトルは任意（例：`全社安全衛生推進統合データベース`）。
   - ※シートの中身は空のままで構いません（連携時に自動作成されます）。

2. **Apps Script を開いてコードを貼り付け**
   - スプレッドシート上部メニューの「拡張機能」>「Apps Script」をクリックします。
   - 既存のコードを全消去し、本リポジトリの [google_apps_script.js](./google_apps_script.js) の内容を丸ごと貼り付けます。
   - 💾 アイコンをクリックして保存します。

3. **ウェブアプリとしてデプロイ**
   - 右上の「デプロイ」>「新しいデプロイ」をクリックします。
   - 種類の選択（⚙️ 歯車アイコン）で **「ウェブアプリ」** を選択します。
   - 設定内容：
     - **次のユーザーとして実行**: `自分`
     - **アクセスできるユーザー**: `全員`（※現場端末からの送信を受け付けるため）
   - 「デプロイ」ボタンを押し、アクセスの承認を行います。
   - 発行された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

4. **アプリ側の基本設定にURLを入力**
   - 安全衛生推進者アプリを開き、画面右上の「⚙️ 設定」をクリックします。
   - 「🏢 本社スプレッドシート連携 (GAS URL)」欄にコピーした URL を貼り付けます。
   - 「🔌 接続テスト」を押して接続成功を確認後、「保存する」をクリックします。

### 【集約されるデータシート一覧（自動生成）】
- 📋 **職場巡視・パトロール**: 点検箇所、担当者、合否件数、所見、問題項目
- ⚠️ **リスクアセスメント**: 作業名、危険源、重篤度×可能性スコア、判定、是正対策、期限
- 🚨 **ヒヤリハット報告**: 発生日時、場所、状況・経緯、推定原因、再発防止策
- 📚 **安全衛生教育**: 実施日、教育区分、テーマ、受講者数、所見
- ❤️ **健康管理記録**: 実施年月、受診状況、有所見者数、就業配慮事項

## 💡 特長
- **オフライン/端末保存対応**: インターネット未接続時でもブラウザ内（LocalStorage）に安全にデータが保持されます。
- **安心の操作感**: 連携URLを設定しない場合は、現場の単独端末用アプリとしてそのまま利用可能です。
